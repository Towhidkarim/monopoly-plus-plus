# Milestone 8 UI design sources

Exported from the design canvas "Skyline UI directions (M8)" (https://claude.ai/artifact/VhpgcgV3KjWtCykjq4R5Ay, private to the developer). Each `.dc.html` is one artboard: plain HTML with inline styles, plus a small `renderVals()` script holding its sample data. They are the visual spec for the Milestone 8 build (DECISIONS.md D32): read the inline styles for exact colors, radii, spacing and type.

Chosen direction: **A + B mix**, Lamplight panels (dark ink-blue glass, lamp-gold accent) with Tabletop card-stock faces (cream cards, printed frame, striped group band).
