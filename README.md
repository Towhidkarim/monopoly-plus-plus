# Skyline (working title)

A lightweight, juicy, Monopoly-style board game for the browser: isometric living city, strong bots, online play.

```
pnpm install
pnpm dev      # http://localhost:5173
pnpm check    # format check, lint, typecheck, tests
```

Start with `CLAUDE.md`, then `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`, `docs/BOARD.md`.

"Monopoly" is a Hasbro trademark. This project uses original names, theme, and art.
